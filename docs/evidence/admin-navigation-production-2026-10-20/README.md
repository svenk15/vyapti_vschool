## Outcome

Production now uses the accepted quiet Administrator shell and server-derived six-area navigation projection. Each primary area selects its first authorized destination in the documented order, empty areas are omitted, Settings is kept with the utilities, and owner-probed School services remain conditional direct links. Navigation visibility remains a convenience; every destination retains its own live server authorization.

Students now uses the accepted open-directory composition: 218px desktop sidebar, 72px context bar, 28/36px heading, URL-backed Directory/Admissions/Imports links, a contextual Register student action, the existing search/filter/sort controls, and an unboxed semantic table with separate Student, Admission number, Class, Status and Actions columns. Admissions and Imports render their real owner content under the Students area. Staff uses the same local-link recipe while retaining separate Profiles, Access and Availability authority. Register student remains a focused route with Back to Students and no redundant local switcher.

No backend contract, capability, database schema, migration, grant, transaction or seed changed.
