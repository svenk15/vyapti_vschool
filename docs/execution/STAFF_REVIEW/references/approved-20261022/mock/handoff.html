A simpler Staff experience

One connected reference for reviewing the essential journeys before implementation.

Staff Access review →Implemented grants, roles, invitations and recovery.Staff directory →A name opens a Profile. Manage opens useful shortcuts.Add staff →One focused form, then the new Profile.Staff Profile →Section-owned Edit actions and a compact access summary.Access not set up →Explicit setup and review without a default grant.

What to review

  1. Open Manage and edit directly without a Profile detour.
  2. Open the name to inspect the Profile. Each Edit applies only to its own section.
  3. Change a field and use Save. Cancel or Escape with unsaved changes offers a discard choice.
  4. Add a fictional staff member and inspect the resulting Profile.

The accompanying handoff ZIP contains the actual HTML, CSS, JavaScript, font assets, action map and implementation checklist. Production permissions and unresolved owner decisions remain separate. This mock sends no invitations and stores no real data.
