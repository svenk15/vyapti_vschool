## Recovery invariant

A browser timeout is never proof of failure. `UNKNOWN` freezes the selected owner section, submitted values, expected version and original key; it does not freeze or discard either section's local draft. While either owner operation is `UNKNOWN`, both Save actions are disabled and the UI says “Check the pending change before saving another.” Recovery sends only that exact owner operation. After resolution, the appropriate Save actions are enabled. `COMMITTED_REFRESH_FAILED` remains confirmed success and permits GET-only recovery; it does not impose the `UNKNOWN` guard. `STALE_REVIEW_REQUIRED` displays current and attempted facts separately and needs an explicit fresh intent using the newly reviewed version and a new key. Repeated recovery of a found result appends history once. These presentation states do not create a generic receipt owner.
