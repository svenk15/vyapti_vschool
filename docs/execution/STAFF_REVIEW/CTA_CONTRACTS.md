## Recovery invariant

A browser timeout is never proof of failure. `UNKNOWN` keeps the original key and payload. `COMMITTED_REFRESH_FAILED` keeps the confirmed result and permits GET-only recovery. `STALE_REVIEW_REQUIRED` needs a fresh authorized read and an explicit new intent using the newly reviewed version. These presentation states do not create a generic receipt owner.
