# SA-19 — Enroll and place a student

Owner area: students. Reference entry: `#/flow/SA-19`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: student.manage

Outcome: The enrollment and effective placement are saved.

Invariant: One enrollment per student/year and non-overlapping placement intervals; no rewriting frozen rosters.

Recovery: A conflicting placement or open session is shown with a recovery link.

Data ownership: Students owns Enrollment and SectionPlacement; authorized academics references and attendance impact query are checked.
