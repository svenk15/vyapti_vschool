# SA-54 — Review payroll inputs and hand off

Owner area: people-ops. Reference entry: `#/flow/SA-54`. Historical design phase: 6; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: payroll.input / payroll.approve (restricted)

Outcome: Authorized payroll review proceeds with immutable approved run history.

Invariant: A School Administrator role grants no salary access; no payroll formula is assumed in this design.

Recovery: Rule change, missing input or revoked approval stops the run; corrections create a new linked revision.

Data ownership: Restricted PayrollRun, rule version and input references; immutable approval/export evidence. Separate regulatory design required.
