# SA-24 — Confirm, resume and reconcile an import

Owner area: imports. Reference entry: `#/flow/SA-24`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: import.upload

Outcome: Each row reports created, unchanged, failed or remaining with durable receipts.

Invariant: Create-only plus exact no-change re-import in Phase 1; corrections and transfers use explicit workflows.

Recovery: Stale previews require re-preview; lost responses query receipts before retry; avoid replaying successes.

Data ownership: Per-row transaction: Person, Student, Enrollment/Placement, external mapping, row receipt, audit and outbox. Bounded batch processing, no assumed worker.
