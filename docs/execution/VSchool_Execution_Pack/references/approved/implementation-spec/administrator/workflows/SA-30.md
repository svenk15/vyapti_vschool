# SA-30 — Review and export attendance

Owner area: reports. Reference entry: `#/flow/SA-30`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: attendance.read_school + attendance.export

Outcome: A scoped report and bounded export match the underlying session records.

Invariant: Rate = (Present + Late) / (Present + Late + Absent); Excused excluded. Zero denominator is unavailable.

Recovery: Unsubmitted data remains missing; revoked access is rechecked at export generation/download.

Data ownership: Reporting joins scoped sessions, effective records, frozen roster and student identifiers; export reads only allowed columns.
