# SA-17 — Change or revoke staff access

Owner area: staff. Reference entry: `#/flow/SA-17`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: user.manage

Outcome: The next protected request rechecks the changed grant.

Invariant: Do not disable a global identity for a local branch action; prevent removal of the last active administrator.

Recovery: Concurrent revocations serialize; insufficient replacement/admin coverage blocks the action.

Data ownership: Access membership/grant transaction and audit; related assignment reads show impact without rewriting history.
