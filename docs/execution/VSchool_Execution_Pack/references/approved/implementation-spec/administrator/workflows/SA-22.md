# SA-22 — Promote, transfer or leave school

Owner area: students. Reference entry: `#/flow/SA-22`. Historical design phase: 3; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: student.lifecycle.manage

Outcome: A dated lifecycle case records the outcome and preserves source history.

Invariant: Bulk promotion requires preview and per-student results; financial balances do not transfer by moving a student row.

Recovery: Partial results, destination rejection, changed capacity and duplicate confirmation require recoverable receipts.

Data ownership: Students owns LifecycleCase and enrollment changes; Finance/Documents/Guardians use explicit follow-up contracts.
