# SA-32 — Verify and link a parent or guardian

Owner area: families. Reference entry: `#/flow/SA-32`. Historical design phase: 2; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: guardian.relationship.manage

Outcome: A verified child-specific relationship and inactive selected purpose grants are approved. Intended-account acceptance activates only those approved purposes.

Invariant: No mailbox-only or sibling-inherited authorization. Each child-purpose link has verified identity, scope and dates; a draft never grants access.

Recovery: Invalid dates, duplicates, disputed identity, lost authorization and unfinished drafts have explicit recovery. Contact, fee, pickup and consent permissions remain separate.

Data ownership: Guardians owns Guardian and dated StudentGuardianGrant; references organization Person/Student and optional global UserAccount binding.

## Exact catalog steps and fields

### Step 1: Student & adult

Select a student from the authorized branch and the independently verified adult.

| Key | Label | Control | Required | Options |
|---|---|---|---|---|
| student | Student | select | True | ["Branch student by exact authorized ID"] |
| relationship | Relationship | select | True | ["Parent", "Legal guardian", "Authorized caregiver"] |
| adult | Adult’s full name | text | True | [] |
| email | Verified email address | email | True | [] |

### Step 2: Verify & choose access

Mailbox possession is not proof. Record school verification and dates; select at least one independent purpose.

| Key | Label | Control | Required | Options |
|---|---|---|---|---|
| reference | School verification reference | text | True | [] |
| from | Access starts | date | True | [] |
| to | Last day of access (inclusive) | date | True | [] |
| verified | I have verified the relationship and checked restrictions. | checkbox | True | [] |
| attendance | Attendance · read only | checkbox | False | [] |
| notices | School notices · independently selected | checkbox | False | [] |

### Step 3: Review

Review child, adult, purpose and dates before approval. Approval creates an inactive grant.

| Key | Label | Control | Required | Options |
|---|---|---|---|---|
| confirm | Approve connection | confirmation | True | [] |
