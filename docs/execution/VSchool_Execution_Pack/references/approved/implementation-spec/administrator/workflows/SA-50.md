# SA-50 — Resolve reconciliation, adjustment or refund

Owner area: finance. Reference entry: `#/flow/SA-50`. Historical design phase: 5; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: finance.reconcile / refund.approve (delegated)

Outcome: An authorized adjustment or reconciled outcome appends to the ledger.

Invariant: Do not edit posted amounts or double-refund an uncertain provider request.

Recovery: Timeout, duplicate callback, insufficient refundable balance and rejected approval have explicit outcomes.

Data ownership: Finance CreditNote, RefundReservation, Settlement and append-only ledger entries; idempotent provider seam.
