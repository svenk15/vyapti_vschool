# SA-27 — Correct submitted attendance

Owner area: attendance. Reference entry: `#/flow/SA-27`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: attendance.correct

Outcome: A new correction revision appears with actor, reason and time.

Invariant: Only submitted attendance is correctable; compare the expected revision in the same authorized transaction.

Recovery: Another editor’s correction shows a conflict and comparison; unknown result uses the same request receipt.

Data ownership: Attendance appends immutable record/correction revision, audit and outbox; reporting reads the effective revision without destroying the original.
