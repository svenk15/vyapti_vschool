# SA-25 — Schedule attendance sessions

Owner area: attendance. Reference entry: `#/flow/SA-25`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: class.manage

Outcome: The session appears in the assigned teacher’s teaching day.

Invariant: Reject overlapping scheduled sessions for the same primary teacher; roster freezes only when the session opens.

Recovery: Calendar conflict or teacher change explains the exact blocked interval.

Data ownership: Attendance owns AttendanceSession; Academics supplies Offering, Assignment and pinned CalendarRevision. Index both overlap query shapes.

## Exact catalog steps and fields

### Step 1: Session
