# SA-61 — Review connection status and reconcile a sync

Owner area: integrations. Reference entry: `#/flow/SA-61`. Historical design phase: 3; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: integration.read / integration.manage (delegated)

Outcome: A scoped synchronization run has reconciled per-record outcomes.

Invariant: No unreviewed source overwrites; authenticated webhooks deduplicate and reauthorize.

Recovery: Unknown provider outcome, duplicate webhook and mapping conflict stay visible.

Data ownership: IntegrationCredentialRef, SyncRun, WebhookReceipt and owner module commands. No direct writes to another module’s tables.
