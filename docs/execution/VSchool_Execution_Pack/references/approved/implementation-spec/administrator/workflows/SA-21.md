# SA-21 — Move a student to another section

Owner area: students. Reference entry: `#/flow/SA-21`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: student.manage

Outcome: Current and new placement intervals remain contiguous and explainable.

Invariant: Reject unsupported backdated changes; already frozen/submitted rosters remain unchanged.

Recovery: Offer a future valid date when historical attendance conflicts; do not delete and recreate enrollment.

Data ownership: Students closes old SectionPlacement and appends new placement atomically after Attendance impact checks.
