# SA-38 — Capture inquiry and start an application

Owner area: admissions. Reference entry: `#/flow/SA-38`. Historical design phase: 3; phase is not current implementation status.

## Authority and outcome

Invariant: Admission must work without Fees; collect only information needed for the current stage.
