# SA-01 — Sign in and choose a branch

Owner area: home. Reference entry: `#/flow/SA-01`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: authenticated identity + active branch grant

Outcome: The administrator lands on Today in the chosen branch.

Invariant: Recheck institution, branch, membership and module state; return URLs must be allowlisted.

Recovery: Invalid credentials use a generic message; suspended access shows a support route, never another branch’s data.

Data ownership: UserAccount → SchoolMembership → RoleGrant → Organization / School. Read only; session issuance is owned by Access.
