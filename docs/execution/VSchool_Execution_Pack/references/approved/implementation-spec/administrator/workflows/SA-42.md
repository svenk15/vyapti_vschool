# SA-42 — Arrange cover or a timetable exception

Owner area: planning. Reference entry: `#/flow/SA-42`. Historical design phase: 3; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: timetable.cover.manage

Outcome: The supported substitution is visible to the affected staff.

Invariant: Never use shared logins; do not replace historical assignment attribution.

Recovery: Unavailable cover or an already opened session invokes the defined review path.
