# SA-35 — Compose and send a school message

Owner area: communication. Reference entry: `#/flow/SA-35`. Historical design phase: 2; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: communication.send

Outcome: A draft is approved, published or scheduled with a stable notice identity and exact immutable version. Recipients read and explicitly acknowledge through their own workspace.

Invariant: Explicit school-notice purpose and current scope control the audience. Teacher role has no blanket send authority. Read, provider acceptance and acknowledgement remain separate.

Recovery: Changed audience/draft requires renewed review. Lost publication response uses the existing receipt. Scheduled delivery rechecks the approved manifest without silently adding accounts.

Data ownership: Communication Notice/Draft/Version/Recipient/Binding, transaction receipt and initial outbox; Guardians/Access/Students resolve current account/purpose/enrollment.

## Exact catalog steps and fields

### Step 1: Message

Write a clear text notice. Acknowledgement is deliberate receipt, not consent.

| Key | Label | Control | Required | Options |
|---|---|---|---|---|
| title | Subject (up to 120 characters) | text | True | [] |
| body | Message (up to 5,000 characters) | textarea | True | [] |
| ack | Ask recipients to acknowledge | checkbox | False | [] |
| due | Acknowledge by (required when requested) | date | False | [] |

### Step 2: Recipients

Resolve accounts from live approved purpose grants or staff membership; attendance alone is insufficient.

| Key | Label | Control | Required | Options |
|---|---|---|---|---|
| audience | Audience | select | True | ["Parents / guardians of a class", "Parents / guardians in this branch", "Active staff in this branch"] |
| className | Class (when class audience chosen) | select | False | ["Authorized branch class"] |
| email | Also send a verified-email notification | checkbox | False | [] |

### Step 3: Review

Teacher submits for approval; an authorized school publisher confirms current draft and audience.

| Key | Label | Control | Required | Options |
|---|---|---|---|---|
| when | Publish | select | True | ["Now", "At a scheduled time"] |
| scheduled | School-local scheduled date/time (when scheduled) | datetime-local | False | [] |
| reviewed | I reviewed the message, audience, timing and acknowledgement. | checkbox | True | [] |
