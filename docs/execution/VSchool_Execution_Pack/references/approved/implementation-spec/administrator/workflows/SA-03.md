# SA-03 — Switch branch or sign out

Owner area: home. Reference entry: `#/flow/SA-03`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: active target-branch grant

Outcome: New context is resolved on the server, or the session is signed out.

Invariant: Clear scoped caches and protected drafts; reauthorize the destination and never reuse the previous branch’s data.

Recovery: If the target grant was revoked, keep the old context if still authorized and show a safe explanation.

Data ownership: Access session/context read; revoke session on sign-out. No business table writes.
