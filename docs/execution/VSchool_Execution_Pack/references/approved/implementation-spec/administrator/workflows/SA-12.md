# SA-12 — Change calendar or teaching assignment

Owner area: academics. Reference entry: `#/flow/SA-12`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: class.manage / school.manage

Outcome: A supported future-dated change preserves historical references.

Invariant: Block changes affecting frozen/submitted roster history in the first release; substitutions are a later explicit workflow.

Recovery: List conflicting sessions and let the administrator resolve them before retrying.

Data ownership: Owner use case reads dependent AttendanceSession references; new academic revision/dates plus transactional audit.
