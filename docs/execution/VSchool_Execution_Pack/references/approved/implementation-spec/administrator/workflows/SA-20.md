# SA-20 — Review or update a student record

Owner area: students. Reference entry: `#/flow/SA-20`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: student.read / student.manage

Outcome: The permitted correction is saved with a reason and revision.

Invariant: Student 360 panels are separately entitled and authorized; a student view is not authority to edit Fees or Health.

Recovery: Concurrent edits show a comparison; a restricted panel is omitted rather than partially leaking its data.

Data ownership: People owns name facts, Students owns school identity/enrollment; compose reads through approved scoped joins.
