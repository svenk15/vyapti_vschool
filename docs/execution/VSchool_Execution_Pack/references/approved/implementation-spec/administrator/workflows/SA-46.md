# SA-46 — Coordinate assessment setup and marks readiness

Owner area: assessments. Reference entry: `#/flow/SA-46`. Historical design phase: 4; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: assessment.coordinate

Outcome: The assessment moves only when its defined prerequisites are met.

Invariant: School coordination does not imply permission to edit teachers’ marks.

Recovery: Not-entered, absent and exempt are separate; no automatic numeric zero.

Data ownership: Assessment scheme/version and read model of MarkRevision/Moderation; owner use cases enforce role-specific actions.
