# SA-15 — Review invitation or resend access

Owner area: staff. Reference entry: `#/flow/SA-15`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: user.manage

Outcome: The new invitation attempt has an expiry and an honest delivery outcome.

Invariant: Do not activate on send, silently retry in a worker, expose tokens or reuse a failed token.

Recovery: Policy tightened, account blocked or expired grant explains why resend is unavailable.

Data ownership: Access token revoke + fresh issue + audit commit before email seam; sanitized delivery failure recorded afterward.
