# SA-02 — Activate or recover an account

Owner area: home. Reference entry: `#/flow/SA-02`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: access activation / recovery policy

Outcome: A generic acknowledgement and permitted recovery instructions are shown.

Invariant: Email resets must satisfy every active institution membership at issue and consume time; operator recovery remains supported.

Recovery: Expired, revoked, failed-delivery and previously consumed tokens cannot be accepted; resend rotates the token.

Data ownership: Access owns invitation/activation/reset tokens, consumption transaction, audit and delivery outcome. Never put secrets in audit.

The available recovery path follows the institution and account-wide trust policy.
