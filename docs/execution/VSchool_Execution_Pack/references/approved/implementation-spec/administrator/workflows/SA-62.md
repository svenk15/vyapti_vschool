# SA-62 — Review activity, privacy or support access

Owner area: settings. Reference entry: `#/flow/SA-62`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: school.audit.read; privacy/support actions need separate authority

Outcome: A safe branch-scoped event is available for review.

Invariant: The administrator cannot delete audit history, grant operator impersonation or run an unrestricted data export.

Recovery: Restricted events show permitted metadata only; unsupported privacy requests route to the designated authority.

Data ownership: Append-only audit read model scoped by branch and capability; safe diff and request IDs only.
