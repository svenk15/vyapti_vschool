# SA-13 — Create a staff profile

Owner area: staff. Reference entry: `#/flow/SA-13`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: people.manage / current repository equivalent

Outcome: An organization Person and branch Employee profile are linked deliberately.

Invariant: Email/name matches are not proof of identity or authority to merge people.

Recovery: Exact identity candidates need an explicit review; duplicate employee codes are rejected.

Data ownership: People owns Person and Employee with scoped uniqueness and explicit links. No account is automatically created.

## Exact catalog steps and fields

### Step 1: Staff details

A staff record can exist without a login.

| Key | Label | Control | Required | Options |
|---|---|---|---|---|
| first | First name | text | True | [] |
| last | Last name | text | False | [] |
| code | Employee code | text | True | [] |
| email | Work email | email | False | [] |

### Step 2: Employment

Choose a role label and effective employment dates.

| Key | Label | Control | Required | Options |
|---|---|---|---|---|
| type | Staff category | select | True | ["Teaching", "Administration", "Support"] |
| from | Start date | date | True | [] |
