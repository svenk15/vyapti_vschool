# SA-11 — Create an offering and assign a teacher

Owner area: academics. Reference entry: `#/flow/SA-11`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: class.manage

Outcome: A dated teaching assignment is saved.

Invariant: Identity binding and teacher eligibility are separate from account activation; enforce non-overlap under the documented guard.

Recovery: A teacher becoming ineligible before save rejects the command and retains safe form input.

Data ownership: Academics owns Offering and Assignment; published People/Access contracts verify Employee, Person binding and membership.
