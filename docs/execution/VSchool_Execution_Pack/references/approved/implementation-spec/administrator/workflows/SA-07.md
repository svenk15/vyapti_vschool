# SA-07 — Review branding and school sign-in

Owner area: settings. Reference entry: `#/flow/SA-07`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: branding.read; branding.write requires explicit delegation

Outcome: A delegated publisher can publish; other school administrators can request a branding update.

Invariant: Branding never changes authorization, status semantics, layout or external redirect destinations.

Recovery: Reject unsafe assets, unreadable colors and an already claimed public slug; keep the published revision unchanged.

Data ownership: BrandProfile / revision owned by Branding, linked to Organization and authorized School. Public projection contains no private settings.
