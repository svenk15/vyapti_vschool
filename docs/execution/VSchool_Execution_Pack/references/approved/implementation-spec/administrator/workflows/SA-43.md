# SA-43 — Review learning readiness and follow-up

Owner area: planning. Reference entry: `#/flow/SA-43`. Historical design phase: 3; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: learning.overview; content authority delegated

Outcome: An authorized follow-up points to the owning learning record.

Invariant: Do not reveal draft feedback to guardians or auto-score missing work as zero.

Recovery: Revoked enrollment or assignment restricts content; attachments remain private and scanned.

Data ownership: Learning read projection of Assignment/SubmissionRevision/Feedback; follow-up command does not publish teacher drafts.
