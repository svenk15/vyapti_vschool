# SA-45 — Issue a certificate or publish a form

Owner area: documents. Reference entry: `#/flow/SA-45`. Historical design phase: 3; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: document.issue / form.publish

Outcome: An issued revision has a reference and controlled download.

Invariant: Do not overwrite issued documents; corrections issue a new linked version.

Recovery: Unavailable source data and revoked recipient grants prevent issue/download.

Data ownership: DocumentTemplateVersion → immutable issue snapshot or FormSchemaVersion/FormResponse, with signed-download authorization.
