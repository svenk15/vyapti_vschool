# SA-63 — Review an AI-assisted explanation or draft

Owner area: assistant. Reference entry: `#/flow/SA-63`. Historical design phase: 7; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: assistant.use + every source capability

Outcome: A reviewed draft or explanation can support a human decision.

Invariant: No unrestricted SQL, autonomous record changes or sensitive health/disciplinary inference.

Recovery: Missing evidence, provider outage and suspicious retrieved instructions trigger abstention or a safe fallback.

Data ownership: AssistantSession, scoped EvidenceReference and ActionProposal; deterministic calculations from owner read contracts.

## Exact catalog steps and fields

### Step 1: Choose an allowed task

The assistant retrieves only evidence already permitted to you.

| Key | Label | Control | Required | Options |
|---|---|---|---|---|
| task | Task | select | True | ["Explain a permitted attendance report", "Draft a school notice"] |
| question | Question / draft request | textarea | True | [] |

### Step 2: Check sources

The answer must carry source references and an as-of time.

| Key | Label | Control | Required | Options |
|---|---|---|---|---|
| sources | I have checked the cited evidence and any uncertainty. | checkbox | True | [] |

### Step 3: Use a reviewed draft

Business changes still use normal authorized forms.

| Key | Label | Control | Required | Options |
|---|---|---|---|---|
| next | Next action | select | True | ["Keep as a draft", "Open the normal action form"] |
