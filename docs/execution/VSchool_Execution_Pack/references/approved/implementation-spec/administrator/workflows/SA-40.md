# SA-40 — Accept an offer and enroll once

Owner area: admissions. Reference entry: `#/flow/SA-40`. Historical design phase: 3; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: admissions.convert + student.manage

Outcome: One student conversion receipt links the application to enrollment.

Invariant: A repeated request returns the same conversion; do not create duplicate students or automatic guardian grants.

Recovery: Invalid capacity, changed acceptance or incomplete identity evidence pauses conversion safely.

Data ownership: Admissions conversion intent and Students owner transaction produce durable linkage; optional Finance/Documents handoffs are explicit.
