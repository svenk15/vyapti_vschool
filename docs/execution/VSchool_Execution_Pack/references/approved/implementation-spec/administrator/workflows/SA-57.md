# SA-57 — Receive, issue or return stock and assets

Owner area: facilities. Reference entry: `#/flow/SA-57`. Historical design phase: 6; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: inventory.manage (delegated)

Outcome: An append-only movement and current custody state are available.

Invariant: No negative stock unless explicitly approved by a versioned policy; cross-branch transfer requires both scopes.

Recovery: Concurrent issue or missing custody acknowledgement leaves a reviewable exception.

Data ownership: Inventory StockMovement ledger and Asset/CustodyAssignment; owner transaction controls available stock.
