# SA-05 — Resolve a daily exception

Owner area: home. Reference entry: `#/flow/SA-05`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: capability of the underlying action

Outcome: The source record opens with its branch and status intact.

Invariant: Never turn a pending register into an absence; the dashboard is a read model.

Recovery: An already resolved or revoked item refreshes safely and explains why it is no longer actionable.

Data ownership: Read AttendanceSession, ImportJob and permitted access status; no separate shadow business state.
