# SA-09 — Create an academic year and calendar

Owner area: academics. Reference entry: `#/flow/SA-09`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: school.manage

Outcome: A valid year and immutable calendar revision are available.

Invariant: Reject invalid/reversed ranges and incompatible scheduled dates; existing sessions keep their pinned calendar revision.

Recovery: A concurrent calendar update requires reload and impact review.

Data ownership: Academics owns AcademicYear and CalendarRevision; sessions reference the selected calendar version.

## Exact catalog steps and fields
