# SA-49 — Generate invoices and collect payment

Owner area: finance. Reference entry: `#/flow/SA-49`. Historical design phase: 5; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: finance.invoice / finance.collect (delegated)

Outcome: Posted invoice, verified payment and receipt retain separate states.

Invariant: A browser success return is not proof of payment; callbacks authenticate and deduplicate.

Recovery: Unknown outcomes are reconciled before retrying; partial payment leaves an explicit balance.

Data ownership: Finance Invoice/Line snapshots, Payment, Allocation and Receipt, with unique provider/reference constraints and audit.
