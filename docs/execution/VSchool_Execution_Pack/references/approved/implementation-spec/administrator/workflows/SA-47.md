# SA-47 — Approve, publish or correct results

Owner area: assessments. Reference entry: `#/flow/SA-47`. Historical design phase: 4; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: assessment.approve / results.publish (explicit)

Outcome: Published results or a linked correction are available with a timestamp.

Invariant: Draft edits never leak; approval and publication cannot race past changed marks.

Recovery: Changed revision requires reapproval; partial delivery does not unpublish the valid result.

Data ownership: ResultPublicationManifest references approved immutable MarkRevisions; Communication queues minimal notices.
