# SA-34 — Change, restrict or revoke a guardian link

Owner area: families. Reference entry: `#/flow/SA-34`. Historical design phase: 2; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: guardian.relationship.manage

Outcome: The exact child grant or school relationship changes with history preserved; old invitations and protected views recheck current access.

Invariant: Keep portal revocation, relationship end and purpose changes separate. Preserve sibling and other-institution grants and source attendance.

Recovery: If a record is disputed, escalate privately and avoid notifying an unsafe recipient automatically.

Data ownership: Guardians grant revision/revocation, binding read and cancellation/suppression contracts for queued delivery.

## Exact catalog steps and fields

### Step 1: Choose connection and change

The scope and impact stay visible; other children remain unaffected.

| Key | Label | Control | Required | Options |
|---|---|---|---|---|
| connection | Connection | select | True | ["Authorized child connection"] |
| change | Manage access | select | True | ["Change access dates", "Remove portal access", "End relationship"] |

### Step 2: Confirm the intended effect

Date changes require fresh acceptance. Portal removal does not determine legal guardianship. Ending the school record requires a verified decision reference.

| Key | Label | Control | Required | Options |
|---|---|---|---|---|
| reason | Bounded reason or school decision reference | text | True | [] |
| confirm | Confirm the selected action | checkbox | True | [] |
