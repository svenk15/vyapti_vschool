# SA-36 — Resolve failed delivery or missing acknowledgement

Owner area: communication. Reference entry: `#/flow/SA-36`. Historical design phase: 2; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: communication.manage

Outcome: A permitted delivery attempt, reminder, version, withdrawal or verified offline response is recorded while previous evidence remains intact.

Invariant: Never infer acknowledgement, silently overwrite a published notice or blindly retry Unknown. Current recipient grants and independent offline-response authority are checked.

Recovery: Withdrawal/revocation/version change blocks stale reads and acknowledgements; already-sent email cannot be recalled. Correction retains the same NoticeId and asks for current-version acknowledgement.

Data ownership: Immutable NoticeVersion, append-only DeliveryAttempt and exact-version Acknowledgement with recipient and actual actor/method; scoped current grant queries and safe receipts.
