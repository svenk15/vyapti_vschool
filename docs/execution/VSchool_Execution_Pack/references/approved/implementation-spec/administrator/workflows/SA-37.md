# SA-37 — Review a family request

Owner area: communication. Reference entry: `#/flow/SA-37`. Historical design phase: 2; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: family.request.review

Outcome: The family sees the decision and any next step.

Invariant: Do not let a general message edit attendance, identity or financial records directly.

Recovery: Revoked child relationship blocks further disclosure; keep an internal audit of the decision.

Data ownership: Request owner records decision; Students/Documents/People execute permitted changes via explicit contracts.
