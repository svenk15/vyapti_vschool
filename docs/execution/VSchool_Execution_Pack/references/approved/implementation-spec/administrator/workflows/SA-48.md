# SA-48 — Configure fees and concessions

Owner area: finance. Reference entry: `#/flow/SA-48`. Historical design phase: 5; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: finance.plan.manage / concession.approve (delegated)

Outcome: An approved plan revision can be used to generate invoice snapshots.

Invariant: General school administrators have coordination access only unless explicitly granted finance authority.

Recovery: In-use fee plans version forward; negative/invalid money and unsupported currency are rejected.

Data ownership: Finance owns FeePlanVersion and Concession decision. Store money in exact minor units with currency; no floats.
