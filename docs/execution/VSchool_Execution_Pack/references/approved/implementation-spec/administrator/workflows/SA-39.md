# SA-39 — Review application and make a decision

Owner area: admissions. Reference entry: `#/flow/SA-39`. Historical design phase: 3; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: admissions.review / decision delegation

Outcome: The decision revision and next action are recorded.

Invariant: Seat reservation and offer expiry must be atomic; subjective notes remain restricted.

Recovery: Last-seat conflicts and expired decision authority require refreshed capacity and delegation.
