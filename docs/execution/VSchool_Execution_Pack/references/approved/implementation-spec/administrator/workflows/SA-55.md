# SA-55 — Catalog and circulate library items

Owner area: library. Reference entry: `#/flow/SA-55`. Historical design phase: 6; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: library.circulate (delegated)

Outcome: The loan or reservation is recorded with a clear due date.

Invariant: Only one active loan per physical copy; fines are optional Finance integration.

Recovery: Already loaned, hold queue conflict, lost item and duplicate scan have explicit outcomes.

Data ownership: CatalogItem, PhysicalCopy, Loan, Reservation and versioned policy. Lock copy/hold state in circulation transaction.
