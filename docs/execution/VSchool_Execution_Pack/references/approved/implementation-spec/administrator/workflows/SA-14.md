# SA-14 — Grant staff sign-in access

Owner area: staff. Reference entry: `#/flow/SA-14`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: user.manage

Outcome: A pending membership/grant is created and the permitted activation path is shown.

Invariant: Preserve operator-issued IAM paths; invite email does not prove employee identity. Last-admin safeguards remain.

Recovery: A failed delivery is visible to the authorized manager; resend revokes the old token.

Data ownership: Access owns UserAccount, SchoolMembership, RoleGrant and Invite/AccountActivation; People binding is checked through its published contract.
