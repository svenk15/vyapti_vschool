# SA-08 — Review modules and request a capability

Owner area: settings. Reference entry: `#/flow/SA-08`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: module status read; commercial changes are institution/operator authority

Outcome: The administrator gets a clear handoff to the institution contact.

Invariant: Licensed, released, branch-enabled and authorized are four separate checks. No self-service license escalation.

Recovery: Disabling a module retains data and must respect open obligations; request submission alone changes nothing.

Data ownership: Tenancy read model for entitlement and branch activation. Proposed change request only if an approved request contract exists; otherwise display contact instructions.
