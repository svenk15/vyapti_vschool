# SA-44 — Collect and review a document

Owner area: documents. Reference entry: `#/flow/SA-44`. Historical design phase: 3; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: document.review + owning module capability

Outcome: The document version and review state are visible to authorized users.

Invariant: No public object URLs; scan failure never becomes a successful upload; expiry and retention follow approved policy.

Recovery: Interrupted upload resumes or retries safely; expired access links reauthorize.

Data ownership: Documents owns FileAsset, ScanResult, DocumentVersion and grant. Owning module references the immutable approved version.
