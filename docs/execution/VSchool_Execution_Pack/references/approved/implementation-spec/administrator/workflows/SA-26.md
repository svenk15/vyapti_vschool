# SA-26 — Monitor and inspect attendance

Owner area: attendance. Reference entry: `#/flow/SA-26`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: attendance.read_school / attendance.read_class

Outcome: The exact session and its submission evidence are shown.

Invariant: School admin is not granted attendance.mark by default; link to assigned teacher, never impersonate them.

Recovery: Cancelled and unsubmitted sessions are distinct from absent pupils; missing denominator displays unavailable.

Data ownership: Read scoped Session → frozen roster → records/revisions, with current authorization and data-as-of timestamp.
