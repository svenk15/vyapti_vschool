# SA-56 — Resolve overdue, lost or inventory discrepancies

Owner area: library. Reference entry: `#/flow/SA-56`. Historical design phase: 6; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: library.manage (delegated)

Outcome: The item and borrower record show the reasoned outcome.

Invariant: Loss/recovery preserves circulation history; no automatic guardian billing without the Finance contract.

Recovery: Concurrent return and loss adjustment reconcile under the copy guard.

Data ownership: PhysicalCopy state, Loan closure/revision, inventory evidence and optional FineCharge event.
