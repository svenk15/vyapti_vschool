# SA-33 — Invite a verified guardian

Owner area: families. Reference entry: `#/flow/SA-33`. Historical design phase: 2; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: guardian.invite

Outcome: An invitation has a visible delivery and acceptance state. Only intended-account acceptance activates the exact child’s approved grant.

Invariant: Recheck identity, trust mode, current policy, grant dates, purpose, restrictions and expected versions at acceptance; never treat parents as staff.

Recovery: Failed delivery cannot be consumed. Explicit resend replaces the old invitation. Expired, replaced, revoked and wrong-account links fail without exposing child data.

Data ownership: Guardians relationship and Access account binding; invite issue/consume with single-use hash, audit and delivery status.
