# SA-06 — Edit branch information

Owner area: settings. Reference entry: `#/flow/SA-06`. Historical design phase: 1; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: school.manage

Outcome: Permitted details are saved with a revision and activity entry.

Invariant: Time zone Asia/Kolkata is read-only after branch creation. Reject a forged change server-side.

Recovery: A stale edit shows the latest saved values and a comparison; never overwrite automatically.

Data ownership: Access owns School changes; Branding/contact read models read the saved revision. Compare expected version under the guard.
