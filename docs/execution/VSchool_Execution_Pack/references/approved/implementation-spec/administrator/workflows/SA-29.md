# SA-29 — Review an absence explanation

Owner area: attendance. Reference entry: `#/flow/SA-29`. Historical design phase: 2; phase is not current implementation status.

## Authority and outcome

Capability described by catalog: attendance.explanation.review

Outcome: The family receives a permitted disposition; attendance changes only through correction.

Invariant: Recheck guardian relationship at request/read/delivery; do not expose restricted notes.

Recovery: Late submission, duplicate explanation and revoked guardian access have separate outcomes.

Data ownership: Guardian/request owner records case; Attendance correction facade optional; Communication delivers under current grants.
