# BE-01 — explicit Students composition configuration

Date: 9 October 2026
Status: VERIFIED; human review PENDING

## Contract

Students and the dependent Imports composition are portable factories. They accept the database URL, signed-cursor secret, released-module manifest and optional clock explicitly. They do not read process environment variables, choose release defaults or substitute an empty secret. `lib/server/student-runtime-configuration.ts` is the hosting boundary that reads and parses environment configuration.

Configuration is validated before a Prisma client or connection pool is constructed. A database URL must be present, a cursor secret must contain at least 32 non-whitespace characters, every release identifier must be a current `ModuleId`, and an optional clock must be callable. Invalid configuration raises the existing `UNAVAILABLE` error and no configuration value is logged. Module-scoped construction preserves the existing shared pool lifetime; authenticated tenant state remains per operation.
