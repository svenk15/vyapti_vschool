# First-release must-have scope

This programme delivers eight connected demonstration journeys without replacing the 250-workflow catalogue in [`workspace-audit/WORKFLOW_STATUS.csv`](../workspace-audit/WORKFLOW_STATUS.csv). A catalogue workflow may remain `PARTIAL` while its explicitly listed must-have subset is complete.

| ID | Journey |
|---|---|
| M01 | Workspace access and trustworthy demo personas |
| M02 | School setup to an operational class |
| M03 | Student registration to family access |
| M04 | Timetable to Attendance and oversight |
| M05 | Notice to read and acknowledgement |
| M06 | Assignment to submission and feedback |
| M07 | Assessment to published report |
| M08 | Missing register to verified resolution |

## Included release operations

The included operations are the exact supported slices listed in [`JOURNEYS.md`](JOURNEYS.md): school and academic setup; staff/Teacher assignment; Student registration, placement, access and CSV import; timetable publication and Attendance reconciliation; Teacher Attendance; factual Student/Parent views; Administrator correction/reporting; text notices and basic calendar events; text Learning submission/feedback; synthetic assessment report publication/download; and Principal operational follow-up.

## Deferred catalogue capabilities

Full admissions, Finance/payments/payroll, Transport/pickup, Library/inventory, extracurricular services, advanced Facilities/Support, conversations/meetings/appeals/general requests, advanced consent/events, advanced Learning/files/offline work, advanced leadership delegation/snapshots/decisions, external integrations and real-provider AI remain outside this programme. Existing code, permissions, data and evidence for those areas are preserved.

## Completion boundary

“Demonstration complete” means the M01–M08 operations run end to end with fictional data, current server authorization, durable owner state, focused verification and reproducible navigation. It does not mean the broader catalogue workflow is complete.

Production readiness remains blocked by TEN-03 restricted-role/RLS proof, retention/provider/scanner operations, restore/load evidence, native accessibility, font portability where recorded, human acceptance and any owner-specific production policy. Synthetic evidence never authorizes real pupil data.
