# Administrator navigation simplification preview

Open `NAVIGATION_PREVIEW.html`. It is an isolated design reference, not an application route. It uses fictional content, performs no API calls and saves nothing.

The visual baseline is the accepted FIRST Student registration reference in `../registration-approved/APPROVED_REGISTRATION.html`. The preview evaluates the proposed six-primary-destination structure and representative Students, Attendance and Academics local navigation.

The access-profile selector is a labelled simulation of the current server visibility contracts. It is not authenticated authorization evidence. Production endpoints must retain their independent authorization.
